DominiMap: A Real-time Indoor Navigation App using BLE for St. Dominic College of Asia

DominiMap is an indoor navigation application designed to help students and visitors navigate the GD1 building of St. Dominic College of Asia. It uses Bluetooth Low Energy (BLE) technology for indoor positioning and provides interactive floor maps, room searching, and navigation routes.

Project objectives

  1. Design and implement BLE-based indoor positioning using Bluetooth Low Energy beacons.
  2. Develop a mobile application connecting indoor positioning with an interactive digital campus map.
  3. Create on-screen directions and routing from a user’s current location to a selected destination.

Key features

  • Indoor positioning with beacon detection and signal-strength monitoring
  • Interactive floor maps and room or facility search
  • Shortest-path routing with Dijkstra’s algorithm and step-by-step directions
  • Dynamic location updates and room or building information retrieval

Software and tools

Flutter (Dart), Flutter Reactive BLE, Node.js / Express, MongoDB Atlas, Firebase, WebSockets, Bruno, Visual Studio Code, Git and GitHub, custom SVG maps, and Dijkstra’s algorithm.

Hardware

  • BLE 5.0 waterproof iBeacon tags with accelerometer sensor
  • Android mobile devices with BLE support

Scope and methodology

The documented scope is indoor navigation within the GD1 building of St. Dominic College of Asia; outdoor navigation and Google Maps integration are not included. Development follows Agile Scrum with iterative sprints, testing, reviews, and continuous improvement.

AssetTrack: Real-Time RFID-Based Asset and Inventory Management System

AssetTrack is an RFID-based asset and inventory management system designed to monitor assets and record their movements between locations. It uses RFID technology and an ESP32-based scanning setup to capture asset movements, send scan information to a backend system, and store records for monitoring and reporting.

Objectives

  1. Register and manage assets.
  2. Associate RFID tags with registered assets.
  3. Record asset movement and scanning activity.
  4. Track asset locations and movement history.
  5. Display asset information and images.
  6. Provide analytics and recent RFID activity.
  7. Support asset searching, filtering, and sorting.
  8. Help improve asset monitoring and inventory management.

Main features

  • Asset registration and RFID tag association
  • Asset information and image display
  • RFID scanning and movement activity records
  • Asset location and movement history
  • Analytics, recent RFID activity, search, filtering, and sorting
  • Web-based asset management and a Flutter application for movement logs
