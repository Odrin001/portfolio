DominiMap: A Real-time Indoor Navigation App using BLE for St. Dominic College of Asia

DominiMap helps students and visitors navigate the St. Dominic College of Asia campus using Bluetooth Low Energy (BLE) beacons as indoor positioning markers. Its interactive campus map, room and facility search, and route guidance offer an accessible alternative to printed maps, signage, and verbal directions.

View project details

Project objectives

  1. Design and implement BLE-based indoor positioning using Bluetooth Low Energy beacons.
  2. Develop a mobile application connecting indoor positioning with an interactive digital campus map.
  3. Create on-screen directions and routing from a user’s current location to a selected destination.

Key features

  • Indoor positioning with beacon detection and signal-strength monitoring
  • Interactive floor maps and room or facility search
  • Shortest-path routing with Dijkstra’s algorithm and step-by-step directions
  • Dynamic location updates and room or building information retrieval

Software and tools

Flutter (Dart), Flutter Reactive BLE, Node.js / Express, MongoDB Atlas, Firebase, WebSockets, Bruno, Visual Studio Code, Git and GitHub, custom SVG maps, and Dijkstra’s algorithm.

Hardware

  • BLE 5.0 waterproof iBeacon tags with accelerometer sensor
  • Android mobile devices with BLE support

Scope and methodology

The documented scope is indoor navigation within the GD1 building of St. Dominic College of Asia; outdoor navigation and Google Maps integration are not included. Development follows Agile Scrum with iterative sprints, testing, reviews, and continuous improvement.
